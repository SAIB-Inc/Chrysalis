# X9: Serializer markers and record members

`[CborSerializable]` and `[PlutusData]` now recognize the Chrysalis attribute types by full name, so qualified names, the `Attribute` suffix and `using` aliases work. Same-named attributes from other namespaces no longer trigger generation. Keep using the short names for shape attributes such as `[CborList]`.

A record class's body properties marked `[CborOrder]` or `[CborProperty]` now join the serialized payload, even in a single declaration. Generated `Create` gains a parameter for each such property, and the generated reader needs a constructor that accepts the serialized members.

A record whose payload members span partial declarations uses `[CborOrder]` for wire order, with members without an order last. If one declaration contains all payload members, declaration order still applies. Keep members in `[CborOrder]` order before moving them into a separate partial file to avoid changing the encoded bytes.
