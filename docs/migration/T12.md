# T12: Ouroboros provider

`Ouroboros` keeps its constructor and methods, and still opens one connection per call. Networks other than Mainnet, Preprod and Preview, output-reference lookups, submissions and failures behave differently.

## Networks

- `NetworkType` is `Mainnet`, `Preprod` or `Preview` for the magics 764824073, 1 and 2, and `Unknown` for any other magic (a devnet, SanchoNet). Before, every other magic read as `Preview`.
- On an `Unknown` network, `TxBuilder` script evaluation without your own evaluator throws `ArgumentOutOfRangeException`, because there is no built-in slot table for that network; before, it used Preview's. Pass an evaluator with `TxBuilder.UseEvaluator` until the SDK reads slot times from the node.
- `Ouroboros.GetNetworkMagic(NetworkType.Preview)` returns 2. `Testnet`, `Unknown` and values outside the enum throw `ArgumentOutOfRangeException`; before, they threw `NotImplementedException` or returned 2. `AddCardanoProvider` with `Provider=Ouroboros` now works for `NetworkType=Preview`.

## Submission

- A transaction is tagged with the era of its body: Conway 6, Babbage 5, Alonzo 4. It was always 6. A transaction read or built without an era (`PostMaryTransaction.Read`, `CborSerializer.Deserialize<PostMaryTransaction>`, `PostMaryTransaction.Create`, `Sign`) gets an inferred body: Conway unless it holds older-only fields. Read with `ITransaction.Read(bytes, era)` to choose the era. Another body type throws `ArgumentException` before any I/O.
- A rejection is `ProviderException` with the message `Ouroboros SubmitTransactionAsync: transaction rejected`. Its `Detail` holds the node's reason as `RejectTx.Describe()` gives it, with each base64 or hex run of more than 128 characters (a script's bytes, for example) shortened to its first and last 8 characters and its length, then limited to 1,024 characters, so a script failure shows its script hash and evaluation error. For the whole reason, submit through `NodeClient` and call `RejectTx.Describe()`.
- A reply that is neither an accept nor a rejection, or that cannot be read, is a non-transient `ProviderException` whose message ends `; the transaction may have been accepted`. Reconcile by transaction id before resubmitting.

## Reads

- `GetUtxoByOutRefAsync` asks the node for that output at its current tip. It returns the output, or `null` when the output is not unspent; before, it threw `NotSupportedException`. The hash must be 64 hexadecimal digits (`ArgumentException`) and the index at most 65,535 (`ArgumentOutOfRangeException`); both are checked before cancellation and I/O.
- `GetUtxosAsync` and `GetUtxoByOutRefAsync` return each output exactly as the node encodes it. An output with no inline datum and no script comes back as `AlonzoTransactionOutput` (the list form) with its datum hash; before, every output was rebuilt as `PostAlonzoTransactionOutput` and a list output lost its datum hash.
- Until the codec fix: `DatumOption()` does not yet read a list output's datum hash; read it with `DatumHash()`, which reads both forms.
- An output with a malformed field makes the read fail with `Ouroboros <operation>: unusable response: <exception type>`.
- When the state-query helpers refuse a query, `Detail` keeps their text, for example `The node's ledger is in era 0, which these helpers cannot query.`

Find affected callers with:

```sh
rg -n 'Ouroboros|GetNetworkMagic|NetworkType\.(Preview|Unknown)|GetUtxoByOutRefAsync|PostAlonzoTransactionOutput|DatumOption\(' --type cs
```
