# Local transaction monitor

## Release returns once it is sent

`LocalTxMonitor.ReleaseAsync` now returns `Task` instead of
`Task<LocalTxMonitorMessage>`. The node sends no reply to a release, so the old
method waited for one until its token was cancelled. It now returns once the
release is sent, and `AcquireAsync` takes a new snapshot on the same
connection. Code that only awaits the call needs a rebuild; code that kept the
returned message drops it. A token that is already cancelled throws
`OperationCanceledException`, and nothing is sent.

Before:

```csharp
LocalTxMonitorMessage reply = await monitor.ReleaseAsync(token);
```

After:

```csharp
await monitor.ReleaseAsync(token);
```

## Has-tx sends the era-tagged id

`HasTxAsync(string, CancellationToken)` now sends the id as the node reads it,
`[era, id]`: the Conway era (6) and the id's 32 bytes. Before, it sent the text,
and the node closed the connection. The text must be 64 hexadecimal digits;
anything else throws `ArgumentException` at the call, before anything is sent.
The new overload `HasTxAsync(EraTxId, CancellationToken)` takes the era and the
32 bytes; for an id of another length, its task throws `ArgumentException` when
awaited, also before anything is sent. `LocalTxMonitorMessages.HasTx` has the
same two overloads, and both throw at the call.

The `HasTx` message's `TxId`, in `Chrysalis.Network.Cbor.LocalTxMonitor`,
changes type from `string` to the new record
`EraTxId(int Era, ReadOnlyMemory<byte> Hash)`. Code that builds a `HasTx`
record passes an `EraTxId`; code that reads `TxId` reads its `Era` and `Hash`.

```csharp
EraTxId id = new(6, Convert.FromHexString(txIdHex));
bool present = ((ReplyHasTx)await monitor.HasTxAsync(id, token)).HasTx;
```

## Measures are 64-bit

`ReplyGetMeasures.Measures` changes from `Dictionary<string, CborList<int>>` to
`Dictionary<string, CborList<ulong>>`, and the two fields of the `Measures`
record from `int` to `ulong`: the node's capacities do not fit 32 bits (the
ex-units steps capacity was 40,000,000,000 on Preprod), and reading them threw
`CborDecodeException`. Code that names these members changes its element
types. `ReplyGetMeasures.Slot` keeps its name; it holds the number of
transactions in the snapshot, not a slot.
