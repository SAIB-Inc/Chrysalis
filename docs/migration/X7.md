# X7: Select the transaction era and read maps by kind

Stand-alone union decoding now needs the era. Pass the era of the bytes, not the current network era:

```csharp
// Before
ITransaction tx = CborSerializer.Deserialize<ITransaction>(bytes);
// After
ITransaction tx = ITransaction.Read(bytes, Era.Conway);
```

Use `ITransaction.Read(bytes, era, out int consumed)` when reading from an input stream. The era-selected reader rejects fields unavailable in the selected era; `CborDecodeException` reports the key and byte offset. Block/header envelope decoding still reads the era from the wire.

`MetadatumMap.Value`, `PlutusMap.Value` and `CborMap.Value` now contain ordered `KeyValuePair` lists. Search the pairs rather than indexing by key; enumerate or filter to see every occurrence. The writers preserve pair order and repeats.

```csharp
// Before
ITransactionMetadatum value = map.Value[key];
// After (matches is a predicate over the decoded key)
var values = map.Value.Where(pair => matches(pair.Key)).Select(pair => pair.Value);
```

A repeated keyed-record field throws. Ledger dictionaries keep the last value in all eras, even when the era's ledger rejects those bytes. The Conway ledger accepts repeated map-redeemer keys through protocol version 11, then rejects them from version 12. Pre-Conway sets still preserve equal elements rather than deduplicating like the ledger. Regenerate blueprint serializers after upgrading.

Plutus tag-102 constructor alternatives fit the existing `int`-valued `ConstrIndex`. An alternative above `Int32.MaxValue` now raises a `CborDecodeException` at the alternative's offset rather than returning a misdecoded constructor.

Other context-free reader changes:

| Before | After |
|---|---|
| `IMultiAsset.Read(bytes)` could guess output. | Read `MultiAssetOutput` or `MultiAssetMint` as required by the owning field. |
| `ITokenBundle.Read(bytes)` could guess output. | Read `TokenBundleOutput` or `TokenBundleMint` as required by the owning field. |
| `IBlock.Read(innerBytes)` could guess an era. | Use `BlockWithEra.Read(envelope)` or the concrete block reader for unwrapped bytes. |
| A consumer union without a discriminator could try each case. | Read the known concrete case or declare a disjoint wire shape; CHCB001/CHCB002 point at the union. |
| `IProtocolParamUpdate.Read` guessed Conway. | Babbage-only keys 12–15 select Babbage; mixing them with Conway-only keys throws. |
| A concrete era-less `PostMaryTransaction` always used Conway for its body. | Key 6 selects an older body; use the era overload to select explicitly. |
| `IPlutusData.Read` could treat unrelated tags as constructors. | Unrelated tags are rejected; use the appropriate CBOR reader. |
| `ICborPrimitive.Read` could accept a tag or select `CborInt` beyond its range. | Tags are rejected; integers above `Int32.MaxValue` that fit `Int64` use `CborLong`. |

- Short constructor forms: `ConstrIndex` is the wire tag (121–127 or 1280–1400), not the logical alternative.
- Tag 102: `ConstrIndex` is the logical alternative. `Create(128, …)` and larger supported alternatives now write tag 102. X35 will unify the two meanings and widen the range.
