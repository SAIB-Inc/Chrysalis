# Migration — X11: Official C# 15 `[Union]` Structs (First Family)

## Summary

The first five CBOR union interfaces in `Chrysalis.Codec` are replaced by 24-byte wire-backed official C# 15 `[Union]` structs (`readonly partial struct` implementing `ICborType`, `IUnion`, and `IEquatable<T>`), dropping the `I` prefix (D73 Q1). Pattern matching and `switch` expressions now dispatch through the C# 15 non-boxing `HasValue` / `TryGetValue` pattern at 0 B heap allocation and are checked by the compiler for exhaustiveness (`CS8509`).

## Renamed Types

| Before (`1.x` / pre-X11) | After (`2.0.0-alpha`, X11) | Namespace | Cases (`1..N`) |
|---|---|---|---|
| `INonce` | `Nonce` | `Chrysalis.Codec.Types.Cardano.Core.Protocol` | `NonceWithHash`, `NonceWithoutHash` |
| `ITarget` | `Target` | `Chrysalis.Codec.Types.Cardano.Core.Certificates` | `StakeCredentials`, `OtherAccountingPot` |
| `IRelay` | `Relay` | `Chrysalis.Codec.Types.Cardano.Core.Certificates` | `SingleHostAddr`, `SingleHostName`, `MultiHostName` |
| `IDRep` | `DRep` | `Chrysalis.Codec.Types.Cardano.Core.Governance` | `DRepAddrKeyHash`, `DRepScriptHash`, `Abstain`, `DRepNoConfidence` |
| `IProtocolParamUpdate` | `ProtocolParamUpdate` | `Chrysalis.Codec.Types.Cardano.Core.Protocol` | `ConwayProtocolParamUpdate`, `BabbageProtocolParamUpdate` |

All 13 case structs now implement `ICborType` directly instead of the removed union interface.

## Before / After

### Construction & passing to APIs (implicit union conversion)
```csharp
// Before:
IDRep drep = Abstain.Create(2);
txBuilder.AddVoteDelegation(credential, drep);
CborList<IRelay> relays = CborList.Create<IRelay>([]);

// After:
DRep drep = Abstain.Create(2); // implicit C# 15 union conversion, 0 B
txBuilder.AddVoteDelegation(credential, drep);
CborList<Relay> relays = CborList.Create<Relay>([]);
```

### Exhaustive pattern matching (0 B, compiler-checked `CS8509`)
```csharp
// Before:
int tag = drep switch
{
    DRepAddrKeyHash k => k.Tag,
    DRepScriptHash s => s.Tag,
    Abstain a => a.Tag,
    DRepNoConfidence n => n.Tag,
    _ => throw new NotImplementedException()
};

// After (removing any case is CS8509; `null` matches `default(DRep)`):
int tag = drep switch
{
    DRepAddrKeyHash k => k.Tag,
    DRepScriptHash s => s.Tag,
    Abstain a => a.Tag,
    DRepNoConfidence n => n.Tag,
    null => throw new InvalidOperationException("Uninitialized DRep.")
};
```

Note: Roslyn 5.12 emits an unreachable `box` for `SwitchExpressionException` in `null =>` switch expressions (0 B at runtime).

### Extension methods (`DRepExtensions`, `CertificateExtensions`)
- `CertificateExtensions.DRep(this ICertificate)` now returns value type `DRep?` (`Nullable<DRep>`) instead of reference type `IDRep?` (`null` for non-vote certificates).
- `DRepExtensions.Tag(this DRep)` throws `CborValidationException` on `default(DRep)` (previously `ArgumentNullException` on `null`), and `DRepExtensions.KeyHash(this DRep)` returns `null` on `default(DRep)` as well as on `Abstain` and `DRepNoConfidence`.

### Value semantics, borrowed-storage lifetime, wire integrity, `default`, equality, and boxing avoidance
- **Borrowed `ReadOnlyMemory<byte>` lifetime (`CborSerializer` contract):** Wire-backed union structs store a slice of the caller's input `ReadOnlyMemory<byte>` rather than copying on the hot path. Keep that backing storage valid and unmodified while the union is in use (including when retaining a slice over a reused receive buffer); copy the input before decoding (e.g. `bytes.ToArray()`) if an independent lifetime is required.
- **`default(Union)`:** Inspectable and non-throwing (`HasValue == false`, `Value == null`, `Raw.IsEmpty == true`, `u is null == true`, `TryGetValue` returns `false`), but **not serializable** (`Write` / `CborSerializer.Serialize` throws `CborValidationException`).
- **Discriminant, arity & wire integrity:** Both direct `Union.Read(...)` (throwing `CborDecodeException`) and public union constructors (throwing `CborValidationException`) enforce exact single-item completeness, list `[minItems, maxItems]` arity, and case-discriminant validity. Uninitialized required-field structs (`default(Abstain)`), wrong-tag values (`Abstain.Create(3)`), truncated arrays (`[1, null]` for `SingleHostName`), or `CborRecord` class cases with stale/truncated/mismatched `Raw` throw `CborValidationException`; construct cases via `.Create(...)` or `.Read(...)`.
- **`ProtocolParamUpdate` era-key rules:** Public `ProtocolParamUpdate` constructors reject opposite-era-exclusive keys (Conway keys `25..33` in `BabbageProtocolParamUpdate`, Babbage keys `12..15` in `ConwayProtocolParamUpdate`) and mixed-era maps with `CborValidationException`. Common-only maps (`{}` or `{0: 44}`, sharing keys `0..11` and `16..24` with identical wire encodings and no era tag) are allowed in either constructor (preserving the CLR variant in memory), while re-reading common-only bytes through `ProtocolParamUpdate.Read` deterministically selects `ConwayProtocolParamUpdate`; era-exclusive keys round-trip their era uniquely.
- **Equality:** `Equals`, `GetHashCode`, `==`, and `!=` compare `(kind, Raw)` handle equality in O(1) at 0 B (matching `CborList<T>`, `CborMap<K, V>`, `Address`, and `CborEncodedValue`).
- **Avoid boxing:** Prefer `switch`, `is CaseType`, or `TryGetValue(out CaseType)` over reading `.Value` or converting a union struct to `IUnion`, `ICborType`, or `object`.
- **Custom `[Union]` structs in consumer code:** Declare `[CborSerializable, CborUnion(typeof(Case1), typeof(Case2)), Union] public readonly partial struct MyUnion : ICborType;` (top-level public non-`ref` `readonly partial struct` without `[CborMap]`/`[CborList]`/`[CborConstr]`/`[PlutusData]`; generic unions use open generic tokens, e.g. `[CborUnion(typeof(Some<>), typeof(None<>))]`; nested union cases and cross-assembly multi-field `[CborList]` types with ambiguous `[CborOrder]` are rejected by `CHCB007`). Legacy `[CborUnion]` interfaces and record hierarchies remain supported during the `X11`–`X17` rollout.
