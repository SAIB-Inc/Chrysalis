# WA7: Byron address decoding, pointer addresses, and CIP-0019 validation

`Address` adds read-only Byron bootstrap decoding, full CIP-0019 pointer address construction and decoding, Plutus stake-reference conversion, and strict CIP-0019 payload validation.

- **Strict CIP-0019 validation (breaking):** `Address` decoding (`Address(byte[])`, `Address(ReadOnlySpan<byte>)`, `FromBytes`, `FromHex`, `Address(string)`, `FromBech32`) now enforces exact per-type CIP-0019 lengths (`Base` 57 bytes, `Enterprise` 29 bytes, `Delegation` 29 bytes, `Pointer` 29 bytes plus canonical VLQ without trailing bytes, `Byron` Byron-v1 CBOR envelope as `cardano-ledger` decodes it (canonical `HDAddressPayload`, `NetworkMagic`, and address type; strictly increasing attribute keys) and IEEE CRC-32), throwing `ArgumentException("addressBytes")` on byte/hex paths and `FormatException` on Bech32/Base58. Chain indexers reading historical pre-Babbage blocks that contain malformed outputs (for example trailing garbage bytes or non-canonical testnet pointers) should retain raw `Chrysalis.Codec` address bytes rather than decoding them with `Chrysalis.Wallet.Address`. Construction (`new Address(network, type, payment, stake)`, `FromCredentials`, `FromScriptHash*`, `FromPointer`) now also enforces 28-byte credential hashes and canonical pointer bytes (`ArgumentException`).
- **`ToPlutusAddress()` on stake-only, pointer, and Byron addresses (breaking):** Calling `ToPlutusAddress()` on `Delegation` or `ScriptDelegation` previously produced a `PlutusAddress` with an empty 0-byte payment credential; it now throws `NotSupportedException`. `Byron` also throws `NotSupportedException`, and pointer addresses continue throwing `NotSupportedException` pointing callers to `ToPlutusStakeReference()` or `GetPointer()`.
- **Read-only Byron address decoding:** Adds `AddressType.Byron = 8`, `ByronAddressType` (`PublicKey = 0`, `Script = 1`, `Redeem = 2`; tag `1` is accepted per Pallas/WA7 scope though rejected by `cardano-ledger`), `ByronAddressInfo`, `Address.Era` (reusing `AddressEra`), `Address.Byron`, `Address.FromBase58`, and `Address.ToBase58`. Byron instances copy raw bytes defensively on both ingress (`Address(byte[])`) and egress (`ToBytes()`); `IsDaedalus` and `IsIcarus` indicate payload attribute layout rather than wallet provenance.
- **Pointer addresses & Plutus stake references:** Adds `AddressPointer` (canonical big-endian 7-bit VLQ `ToBytes`, `TryWriteBytes`, `FromBytes`, `TryFromBytes`), `Address.FromPointer`, `Address.GetPointer`, and `Address.ToPlutusStakeReference` (returning `ICborOption<IReferenced<ICredential>>` with `PointerRef<ICredential>` for pointer addresses without changing `Chrysalis.Codec`). Pointer construction produces wire bytes only; from the Conway ledger era, new pointer addresses cannot be added to Mainnet.
- **Dependency hygiene:** `Chrysalis.Wallet.csproj` adds a direct `<PackageReference Include="SimpleBase" />` referencing the `SimpleBase` package already shipped in `Chrysalis.Codec`'s dependency closure (zero new runtime NuGet packages) and keeps IEEE 802.3 CRC-32 private inside `ByronAddressInfo`.
