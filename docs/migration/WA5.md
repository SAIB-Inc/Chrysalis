# WA5: Bech32 validation, API cleanup, and span overloads

`Bech32Util` and `Address` tighten BIP-0173 validation, remove two unused public helpers, and add `ReadOnlySpan<byte>` overloads across wallet and Ed25519 entry points.

- `Bech32Util.Decode` (and `Address.FromBech32` / `new Address(string)`) now enforces BIP-0173 HRP character range (ASCII 33–126) and length (1–83; Cardano addresses longer than 90 characters remain supported per CIP-0019), and throws `FormatException` for invalid 5-to-8-bit padding (previously `ArgumentException`). `Bech32Util.Validate` enforces the same rules without throwing.
- `Bech32Util.Encode` now normalizes uppercase ASCII letters (`A`–`Z`) in the HRP to lowercase per BIP-0173 so encoded strings have valid lowercase checksums; lowercase HRPs are unchanged.
- `new Address(networkType, addressType, payment, stake)` and `Address.FromCredentials` now throw `ArgumentNullException` with `ParamName` `"stake"` (previously `"secondArray"`) when building a `Delegation` or `ScriptDelegation` address with a `null` stake credential.
- The unused public methods `Bech32Util.ExtractPaymentAndDelegation(byte[])` and `Bech32Util.ConvertBits(byte[], int, int, bool)` have been removed. Use `Address.GetPaymentKeyHash()` / `Address.GetStakeKeyHash()` instead of `ExtractPaymentAndDelegation`; arbitrary-width bit regrouping has no public replacement in `Bech32Util`.
- Additive `ReadOnlySpan<byte>` overloads were added to `Bech32Util.Encode`, `HashUtil.Blake2b256`/`Blake2b224`/`Blake2b160`, `Address` (`new Address(ReadOnlySpan<byte>)`, `FromBytes`, `FromScriptHash`, `FromScriptHashWithStake`), and the eight canonical `Ed25519` operations (`Verify`, `PublicKeyFromSeed`, `SeedAndPublicKeyFromSeed`, `SignWithSeedAndPublicKey`, `SignWithExtendedKey`, `PublicKeyFromExtendedKey`, `GetPublicKey`, `PointAdd`). Legacy `Ed25519` aliases (`Sign`, `SignCrypto`, `ExpandedPrivateKeyFromSeed`) remain `byte[]`-only; span callers should use the canonical methods.
- `Address(byte[])` and `Address.FromBytes(byte[])` keep their existing caller-array retention, while `Address(ReadOnlySpan<byte>)` and `Address.FromBytes(ReadOnlySpan<byte>)` validate the header before copying into an owned array.
