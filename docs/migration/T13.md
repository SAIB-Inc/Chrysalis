# T13: slot and time for any network

A `SlotNetworkConfig` now describes a network's whole slot history: when slot 0 began, each era's first slot and slot length, and the first slot whose time is not yet fixed. `Ouroboros` reads it from the node and `Kupmios` from Ogmios, so a script that checks its validity range evaluates on a devnet or any other network.

## SlotNetworkConfig (breaking)

- `SlotNetworkConfig` is a sealed class, no longer a record: `new SlotNetworkConfig(systemStart, eras, endSlot)`, with `SystemStart`, `Eras` (each a `SlotEra(StartSlot, SlotLengthMilliseconds)`, oldest first, the first at slot 0) and `EndSlot` (null when there is no end).
- Removed: `ZeroTime`, `ZeroSlot`, `SlotLength`, the three-number constructor, value equality and `with`. For a network with one slot length, write `new SlotNetworkConfig(systemStart, [new SlotEra(0, 1000)])`. To compare two, compare `SystemStart` and `Eras` instead of the objects.
- `Mainnet`, `Preprod` and `Preview` keep their names; Mainnet and Preprod now start with Byron's 20-second slots.
- New: `SlotEra`, and `SlotConversionException`, an `InvalidOperationException`.

## Networks without a built-in SlotNetworkConfig

- `SlotNetworkConfig.FromNetworkType` and `SlotUtil.GetSlotNetworkConfig` throw `SlotConversionException` for `Testnet`, `Unknown` and values outside the enum. Before, `Testnet` gave Preview's and `Unknown` threw `ArgumentOutOfRangeException`.
- Only a script transaction with a validity bound needs one. On such a network:
  - use `Ouroboros` or `Kupmios`, which read it from the node or Ogmios;
  - implement `GetSlotNetworkConfigAsync` in your own provider; over `Blockfrost`, `Koios` or `UtxoRpc`, write a class that forwards the other six members to it and returns your `SlotNetworkConfig`;
  - pass a `SlotNetworkConfig` to `SlotUtil`, `ScriptContextBuilder.EvaluateTx` or `TransactionBuilder.Evaluate`;
  - or give `TxBuilder.UseEvaluator` your own evaluator.
- Warning: `Blockfrost`, `Koios` and `UtxoRpc` pointed at another network through a custom endpoint, with a public `NetworkType`, still use that public network's times, without an error.
- This replaces the T12 note on script evaluation on an `Unknown` network.

## Conversions

- Each era's slot length is used, so Mainnet and Preprod times before Shelley use 20-second slots: Preprod slot 86,399 is 2022-06-20T23:59:40Z (it was 23:59:59).
- A time converts to the slot that holds it, rounded down. A time before the system start, or a slot at or past `EndSlot`, throws `SlotConversionException`; a negative slot throws `ArgumentOutOfRangeException`.
- `GetUTCTimeFromSlot` keeps the system start's ticks, and script contexts get whole POSIX milliseconds, as the ledger gives them. `GetSlotFromUnixTime` and `GetPosixTimeSecondsFromSlot` work in whole seconds, so on a network whose system start is not a whole second only the `DateTime` methods round-trip exactly.

## Providers and TxBuilder

- New `ICardanoDataProvider.GetSlotNetworkConfigAsync`. By default it returns the built-in `SlotNetworkConfig` of `NetworkType`, so existing providers compile unchanged. `Ouroboros` reads the node's system start and era history, and `Kupmios` reads Ogmios's, on every network; `Kupmios` no longer takes slot times from its `NetworkType` argument.
- `TxBuilder` asks its provider once per builder, the first time it runs a script without `UseEvaluator` on a transaction with a validity bound: two more queries with `Ouroboros` or `Kupmios`.
- A validity bound at or past `EndSlot` makes `Complete()` throw `SlotConversionException`, as the node would refuse the transaction. With `Blockfrost`, `Koios` or `UtxoRpc` on `Testnet`, such a transaction now throws `SlotConversionException` where Preview's times were used; one without bounds is unaffected.
- `ScriptContextBuilder.EvaluateTx` and `BuildTxInfoV3` accept a null `SlotNetworkConfig` for a transaction without validity bounds.

Find affected callers with:

```sh
rg -n 'new SlotNetworkConfig\(|\.ZeroTime|\.ZeroSlot|\.SlotLength\b|NetworkType\.Testnet' --type cs
```
