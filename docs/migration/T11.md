# T11: Kupmios provider

Normal `Kupmios` callers keep the same methods, but `GetParametersAsync` now reads live parameters from Ogmios instead of returning a built-in copy. If you used `Kupmios` offline for parameters, stubbed its HTTP calls, or referenced the removed default parameter models or `KupoValue` widths, update those call sites.

## Parameters

- `GetParametersAsync` POSTs `queryLedgerState/protocolParameters` to the configured Ogmios endpoint on each call. Values, the protocol version and Conway governance values come from the node.
- `NetworkType` no longer selects protocol parameters, and `NetworkType.Unknown` no longer throws `NotSupportedException`.
- Failures follow the provider contract (`ProviderException` / `ProviderStatusException`) with endpoint redaction, cancellation and the Ogmios client timeout (30 s).
- Every Conway field read is required; a Babbage-era answer without governance fields is an unusable response.
- Ratios are parsed as exact `n/d` fractions from Ogmios's UTF-8 strings. The reference-script fee base arrives from Ogmios as a JSON number, so a non-terminating ratio would arrive rounded.
- HTTP stubs of `Kupmios` (including `TransactionTemplateBuilder` and `GetInputsAsync`) must now answer the Ogmios parameter POST.

## Outputs

- `KupoValue.Coins` and `KupoValue.Assets` values are `ulong` (up to `ulong.MaxValue`), replacing `long`.
- A Kupo match whose reference script is unresolved (`script_hash` set with null `script`), lacks `script_hash`, or does not hash to `script_hash` is an unusable response; one such output causes the whole lookup to throw.
- A Kupo match whose `datum_hash` is present and not 64 characters long is an unusable response; for non-inline datums its hex bytes are also decoded (non-hex fails as unusable), whereas an inline datum's `datum_hash` is only length-checked.

## Removed types

- `PParamsDefaults` and `ProtocolParametersResponse` (`Chrysalis.Tx.Models`) are removed. There is no offline copy of Mainnet or Preview parameters any more: call a provider's `GetParametersAsync`, or construct `ProtocolParams` directly.

## Number parsing

Parameter integers, Ogmios ratio strings and Kupo quantities are parsed directly from the UTF-8 response bytes without intermediate string conversions.

Find affected callers and stubs with:

```sh
rg -n 'PParamsDefaults|ProtocolParametersResponse|KupoValue|Kupmios' --type cs
```
