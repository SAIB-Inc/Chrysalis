# T19: simple outputs in the ledger's short (list) form

Builders now write an output with neither an inline datum nor a reference script in the ledger's list form (`AlonzoTransactionOutput`), as cardano-cli does, so the same inputs give different transaction bytes and a different transaction id than 1.x; read such outputs through the `ITransactionOutput` extensions (`DatumHash()` for a datum hash), not as `PostAlonzoTransactionOutput`.
`TransactionBuilder.AddOutput(OutputBuilder)` no longer writes the raised minimum-ADA coin back into the caller's `OutputBuilder`, so an `OutputBuilder` used again is raised from the coin it was created with, not from an earlier raise.
