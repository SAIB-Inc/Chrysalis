# Third-party notices

This list covers third-party files and ports retained in Chrysalis, not dependencies installed by a package manager. The adjacent licence text and manifests identify which files each source covers. A comparison pin identifies reproducible source bytes or, for a port, the referenced source; it does not imply that the original import recorded a revision. The manifests list modifications to retained files. Add an entry and the source's licence, any NOTICE, and per-file provenance in the same change that copies third-party files.
